# 🍷 Adega Pro - Sistema Integrado de Gestão e Catálogo de Vinhos

> Um aplicativo responsivo, didático e intuitivo, desenvolvido para otimizar a gestão de estoque, catálogo de vinhos e controle de adegas com alta performance e usabilidade.

🔗 **Acesse a aplicação rodando ao vivo:** [https://projetoadega.netlify.app/](https://projetoadega.netlify.app/)

---

## 🚀 Sobre o Projeto
Este aplicativo foi projetado para simplificar o controle de estoque e a consulta de rótulos de vinhos, oferecendo uma experiência fluida tanto para entusiastas quanto para a gestão comercial. Desenvolvido com foco em arquitetura limpa (Clean Code), o sistema combina facilidade de uso, organização visual e rapidez na tomada de decisões.

## ✨ Funcionalidades Principais

### Experiência do Usuário (UX)
*   **Interface Intuitiva:** Design humanizado e moderno, focado em agilizar o cadastro e a localização de rótulos.
*   **Design Responsivo:** Otimizado para navegação contínua em dispositivos móveis, tablets e computadores.

### Gestão e Controle
*   **Catálogo de Rótulos:** Organização detalhada por tipo, safra, vinícola, país e harmonização.
*   **Controle de Estoque:** Entrada e saída de garrafas em tempo real com alertas de quantidade mínima.
*   **Filtros Avançados:** Busca rápida por características específicas da bebida ou faixa de preço.

---

## 🛠️ Tecnologias e Clean Code
*   **Tecnologias Base:** React, TypeScript, Tailwind CSS, Lucide Icons, Shadcn/UI
*   **Backend & Persistência:** Integração com Supabase para autenticação e gestão de banco de dados em tempo real.
*   **Clean Code:** Código modular, bem estruturado e com clara separação entre a camada de dados e a interface.
*   **Deploy:** Hospedado via Lovable / Netlify.

## 💻 Executando o Projeto Localmente

```bash
# Clone o repositório

# Entre na pasta do projeto
cd projetoadega

# Instale as dependências
npm install

# Inicie a aplicação em modo de desenvolvimento
npm run dev
